Run exactly one split test per platform per week, log every result, and move to the next constraint if you can't beat the control in four tries or one month.

## Why one test per platform per week
1. Multiple simultaneous tests on one platform hide what worked.
2. Steps affect each other (more opt-ins but fewer applications); one change lets you see the full effect.
3. It forces prioritization — don't waste the week's test on red vs bright red.
4. It runs long enough to get real data but not so long you waste time (a week is enough at Hormozi's spend; smaller budgets may need longer).

## Monday routine (used in every portfolio company)
1. Review last week's results; pick the winner per platform.
2. Write results in a log of all tests, so future work starts from accumulated improvements instead of square one.
3. Design the next test to beat the current best version.
Rule: if you can't beat the current version in 4 tries or 1 month, move to the next constraint. When improvement returns fall below what new placements would bring, go "new."

## When to use
Any business running ongoing lead generation that wants systematic improvement.
