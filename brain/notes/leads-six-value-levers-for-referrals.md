Build referral-generating goodwill with six value levers that mirror the parts of an ad: call-out, the four value drivers, and the CTA.

## The six levers
1. **Call-out → sell better customers.** Best-fit customers get the most value, have the most goodwill, refer most.
2. **Dream outcome → set better expectations.** Promise a bit less so you can over-deliver.
3. **Perceived likelihood → get more people better results.** Copy what your best customers did and make everyone do it.
4. **Time delay → faster (and more frequent) wins.**
5. **Effort and sacrifice → keep making the product better** (monthly improvement loop).
6. **Call to action → tell them what to buy next.**

Each lever: more value → more goodwill → more referrals.

## When to use
Planning a referral strategy: fix goodwill first, then capitalize on it with the seven ways to ask.
