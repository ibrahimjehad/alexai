Strangers don't know you, so make the message look like it came from someone who does: open with one to three things a friend would know about them.

## The idea
A call from an unknown area code is ignored; a local area code is more likely to be answered because it might be someone you know. Push that further: say their name, pause like a normal person, then mention something specific (their recent blog post, how it helped you). Nobody hangs up on that, whereas "Want to buy marketing services?" gets an instant hang-up.

## Steps
1. Research each lead: find 1-3 personal facts (content they made, news, achievements).
2. Compliment it and, ideally, show how it benefited you. People like people who like them.
3. Use it in the email subject line, first chat messages or first sentences of a call.
4. Batch the research, or pay people or software to do it.
5. **Write below a third-grade reading level.** Rewriting Hormozi's cold email template this way got 50% more responses. Run scripts through a free reading-level checker.

## When to use
Every cold message. The fewer total prospects in a niche, the more each message should be personalised.
